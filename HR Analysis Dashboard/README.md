👥 HR Analysis Dashboard – Excel

📌 Project Overview

This project is an HR Analysis Dashboard created using Microsoft Excel.
It provides insights into employee data, workforce composition, salaries, performance, and employee status.

The dashboard transforms raw HR data into meaningful visualizations and key performance indicators to support data-driven HR decisions.

🎯 Project Objectives

- Analyze employee demographics
- Understand department-wise workforce distribution
- Analyze salaries across departments and job roles
- Monitor employee performance ratings
- Analyze active and terminated employees
- Identify workforce trends
- Create an interactive HR dashboard using Excel

🛠️ Tools & Skills

- Microsoft Excel
- Data Cleaning
- Data Analysis

- Pivot Charts

- Data Visualization

📂 Dataset

The HR dataset contains employee information such as:

- Employee ID
- Full Name
- Department
- Job Title
- Email
- Gender
- Hire Date
- Termination Date
- Salary
- Manager ID
- Performance Rating
- Employee Status

📊 Dashboard Features

The dashboard includes analysis of:

- 👥 Total Employees
- 💼 Department-wise Employees
- 💰 Salary Analysis
- ⭐ Performance Rating
- 🚻 Gender Distribution
- 📅 Hiring Trends
- ❌ Employee Termination Analysis
- 🟢 Active vs Terminated Employees
- 🎛️ Interactive Slicers

🔍 Key Business Questions

This dashboard helps answer questions such as:

1. How many employees are currently active?
2. Which department has the highest number of employees?
3. Which job roles have the highest salaries?
4. What is the average salary?
5. How are employees distributed by gender?
6. What is the performance rating distribution?
7. How many employees have been terminated?
8. How has hiring changed over time?
