📊 Expense Analysis Dashboard – Excel

📌 Project Overview

This project is an Expense Analysis Dashboard created using Microsoft Excel.
It helps analyze spending patterns, identify major expense categories, and understand monthly expense trends through interactive visualizations.

🎯 Objectives

- Analyze overall expenses
- Identify the highest spending categories
- Track expenses by month
- Compare spending across different categories
- Create an interactive and easy-to-understand dashboard
- Present key financial insights using Excel data visualization

🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Charts
- Data Cleaning
- Data Analysis
- Dashboard Design

📂 Dataset

The dataset contains 100 expense records with information related to:

- Date
- Category
- Expense Description
- Payment Method
- Amount
- Monthly Expense

The dataset is used to analyze spending patterns and create meaningful visualizations.

📊 Dashboard Features

The dashboard includes:

- 💰 Total Expenses
- 📈 Monthly Expense Trend
- 🏷️ Expense by Category
- 💳 Expense by Payment Method
- 📊 Category-wise Spending Analysis
- 🎛️ Interactive Slicers
- 📌 Key Performance Indicators (KPIs)

🔍 Key Analysis

The dashboard helps answer questions such as:

1. What is the total amount spent?
2. Which category has the highest expenses?
3. Which month has the highest spending?
4. Which payment method is used most frequently?
5. How does spending change over time?
6. Which expense categories contribute most to total spending?
