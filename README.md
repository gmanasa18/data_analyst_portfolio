📊 Sales Performance Dashboard

📌 Project Overview

This project is an Excel-based Sales Performance Dashboard created to analyze sales data and identify important business trends and performance insights.

The dashboard provides an interactive view of sales performance using Pivot Tables, Charts, KPIs, and Slicers.

🎯 Objectives

- Analyze overall sales performance
- Track sales and profit
- Identify top-performing products and categories
- Analyze regional sales performance
- Understand monthly sales trends
- Compare sales performance across different segments
- Support data-driven business decisions

🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Functions
- Data Cleaning
- Data Visualization

📊 Dashboard Features

- Total Sales
- Total Profit
- Total Orders
- Sales by Category
- Sales by Region
- Monthly Sales Trend
- Top Products
- Segment-wise Sales Analysis
- Interactive Slicers for filtering the dashboard

🔍 Key Business Questions

- What are the total sales and profit?
- Which category generates the highest sales?
- Which region performs best?
- What are the monthly sales trends?
- Which products are the top performers?
- Which customer segment contributes the most sales?
