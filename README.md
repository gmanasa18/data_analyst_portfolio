# 📊 Sales Performance Dashboard

## 📌 Project Overview

An interactive Sales Performance Dashboard created using Microsoft Excel to analyze sales, profit, orders, products, categories, and regional performance.

## 🛠️ Tools & Skills Used

- Microsoft Excel
- PivotTables
- PivotCharts
- XLOOKUP
- SUMIFS
- Slicers
- Data Cleaning
- Data Visualization

## 📈 Key Analysis

- Total Sales and Profit
- Monthly Sales Trends
- Sales by Region
- Sales by Category
- Top Performing Products
- Profit Analysis
- Order Performance

## 🎯 Project Objective

The objective of this project is to transform raw sales data into an interactive dashboard that helps identify sales trends, profitable categories, top-performing products, and regional performance.
